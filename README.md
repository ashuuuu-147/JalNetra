# FloodGuard AI — SIH 2026 Implementation Pack

This pack contains the build contract for the FloodGuard AI prototype.

- `PRD.md` — product requirements, workflows, screens, API, database, UX and acceptance criteria.
- `DATA_AND_MODEL_TRAINING_SPEC.md` — real datasets, feature engineering, labels, leakage controls, validation and provenance.
- `AGENTS.md` — strict instructions for an AI coding/implementation agent.
- `DATA_SOURCE_REGISTRY.csv` — source-by-source registry.
- `train_floodguard.py` — real-data-only training entry point.
